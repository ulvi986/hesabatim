# ZapCastSat AI — frontend

Next.js 16 (App Router) + React 19 + Tailwind 4 + shadcn/ui. See the [root README](../README.md) for setup and [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for the design.

```bash
cp .env.example .env.local
npm install
npm run dev      # http://localhost:3000
npm run lint && npx tsc --noEmit && npm run build
```
